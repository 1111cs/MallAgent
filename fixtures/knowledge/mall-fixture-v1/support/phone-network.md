# 手机网络排查

## 手机无法连接 Wi-Fi

当手机无法建立 Wi-Fi 连接时，可先确认密码是否正确、Wi-Fi 是否可被其他设备发现、手机是否能够看到目标网络，并尝试关闭后重新打开 Wi-Fi。

必要时可删除已保存网络后重新连接。若所有设备都无法连接同一网络，应优先怀疑网络或路由器侧问题。

## 已连接 Wi-Fi 但无法上网

如果系统已经显示 Wi-Fi 连接成功，但浏览器或应用无法访问网络，则应区分“无线连接已建立”和“互联网不可用”。

可以检查其他设备是否能通过同一 Wi-Fi 上网、路由器是否正常联网，并尝试重新连接。该场景不应被简单归类为“手机搜索不到 Wi-Fi”。
